* "go build" -> to create an executable file
* "go run " -> to directly run the program without making any exe file
* shorthand is only used when declaring and initializing a variable at the same line
* ** short hand does not work if the variable is to be declared and initialised outside the function scope (IN GLOBAL SCOPE)**
* there is no while/do-while loops in go , ONLY "FOR" loop is there 
    * while loop is implemented using the for loop

* variable type "any" is same as using "interface{}"
